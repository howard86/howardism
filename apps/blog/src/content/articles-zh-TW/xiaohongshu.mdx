## 資料來源

- [Self-GC: Self-Governing Context for Long-Horizon LLM Agents](https://arxiv.org/pdf/2607.00692)

## 這是什麼

**Xiaohongshu**（小紅書，國際上也稱為 **RED**）是中國的社群商務與生活風格內容平台。它被納入本知識庫，不是因為它是消費者產品，而是因為它是**代理程式營運者**：其工程團隊在正式環境中執行長期 LLM 代理程式，並發表了為這些代理程式建置的測量基礎設施。

## 為何與此處相關

Xiaohongshu 撰寫了 **Self-GC**（Xubin Hao、Hongjin Meng、Xin Yin、Jiawei Zhu、Chenpeng Cao — arXiv 2607.00692，2026 年 7 月，`empirical`），這套架構是 [脈絡生命週期管理](/articles/context-lifecycle-management)背後的基礎。對本語料庫而言，它有三點與眾不同：

- **這是部署實例，不是基準測試。** 評估套件取材自該公司代理程式流量中的 **15,141 筆真實軌跡列**（其中 9,075 筆已觸發壓縮），而正式環境的主要結果來自**即時流量的帳戶層級分流**——白天平均輸入 token 數降低 10–15%，降幅最高接近 20%。
- **工作負載不是寫程式。** 這些軌跡屬於辦公室工作類型：將供應商研究整理成比較表、依照使用者明確提出的限制修復試算表、排查排程工作失敗。論文特別指出，這類情境對脈絡管理而言比寫程式更困難，因為程式設計工作可以用 git 歷史記錄、建置日誌及可重新執行的指令作為外部記憶基礎，而辦公室工作流程往往沒有這些資源。
- **這是來自非美國實驗室的系統研究貢獻。** 評估所用的規劃器骨幹模型為 Qwen3.6-Plus、Qwen3.7-Max 和 GLM-5.1——採用中國模型的代理程式技術堆疊，僅在離線評審時使用 GPT-5.5。

論文也提到兩個內部代理程式介面：`context-gc`（互動式聊天清理）和 `skill-gc`（長期技能狀態修剪），顯示他們有一層技能系統，類似於 [Claude Code Best Practices](/articles/claude-code-best-practices) 中介紹的那一層。
